   python rdf_analyzer.py

🐍 Python API:
   from convert_molecular_data import MolecularDataConverter
   
   converter = MolecularDataConverter("system.psf", "traj.dcd")
   
   # Full analysis
   rdf_results = converter.calculate_elemental_distribution(
       elements=['N', 'H', 'O'],
       max_radius=15.0
   )
   
   # Single element
   rdf_n = converter.calculate_radial_distribution(element='N')

📊 SCIENTIFIC ACCURACY
═══════════════════════════════════════════════════════════════════════

Mathematical Rigor:
   • Proper spherical shell volume: V = 4/3π(r³_outer - r³_inner)
   • Density normalization: ρ(r) = N(r) / (V_shell × N_frames)
   • Standard g(r): g(r) = ρ(r) / ρ_bulk
   • Frame-averaged distributions
   • Automated COM tracking

Statistical Analysis:
   • Mean, median, std deviation
   • Percentiles (25%, 50%, 75%)
   • Peak density locations
   • Min/max distances
   • Total atom counts
